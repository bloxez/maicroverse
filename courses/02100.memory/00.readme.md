# Memory Essentials

**Warning**
Running this course intentionally resets project memory blocks so each run starts clean.

## Introduction

This course teaches the persistent memory feature in mAIcro scripts using the core operations:

- `Remember` to create/update memory blocks
- `Recall` to read full blocks or specific paths
- `Forget` to remove a path, a block, or all blocks

You will run a full end-to-end setup script and see assertions confirm behavior after each stage.

## What You Build

The course creates and manipulates two memory blocks:

- `learner_profile`
- `active_session`

You will practice:

1. resetting all memory
2. seeding blocks with JSON data
3. reading block and path values
4. updating individual paths
5. deleting a single path
6. deleting one block
7. resetting all blocks again

## Scripts

- `01.memory_setup.gql` - Master orchestrator that runs all lessons in order
- `02.reset_memory.gql` - Clears all memory blocks
- `03.create_blocks.gql` - Seeds memory blocks with starter JSON
- `04.read_and_assert.gql` - Reads memory content and validates expected values
- `05.update_paths.gql` - Updates specific JSON paths in existing blocks
- `06.forget_examples.gql` - Demonstrates path-level and block-level deletes
- `07.verify_and_reset.gql` - Final checks and full memory reset verification

## How To Run

1. Open the script runner in mAIcro IDE.
2. Execute `scripts/courses/02100.memory/01.memory_setup.gql`.
3. Re-run it once more to confirm repeatability.

## Quick Verification Queries

```graphql
query MemoryCheck {
  Learner: Recall(id: "learner_profile")
  Session: Recall(id: "active_session")
}
```

After `07.verify_and_reset.gql`, both values should be `null` because `Forget()` resets all memory blocks.
