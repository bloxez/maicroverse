# 11000.browser_x4m - Browser X4m Course

This course teaches Browser X4m operations in mAIcro from fundamentals to end-to-end automation patterns. You will learn how to open and manage sessions, navigate pages, extract DOM data, interact with forms, upload files, capture screenshots, and run complete multi-step journeys.

## Safety Notes

- This course is designed to be repeatable.
- Browser sessions are explicitly closed in lesson scripts where needed.
- `11.close_all.gql` is included as a dedicated safety cleanup step.
- The setup orchestrator runs all lessons in order without requiring manual edits.

## What You'll Build

- Confidence using core Browser X4m operations.
- Reliable interaction patterns for selectors, waits, keyboard/mouse actions, and form filling.
- Structured extraction outputs using DOM evaluation.
- A complete repeatable end-to-end browser workflow.

## Script Map

1. `01.setup.gql`
   - Master orchestrator that runs steps `02` through `12` using `DbExecute`.
2. `02.open_list_close.gql`
   - Open a session, list active sessions, close it.
3. `03.goto_extract.gql`
   - Navigate and extract text/html/attributes.
4. `04.wait_click_keyboard_mouse.gql`
   - Waits, click, keyboard, mouse, and evaluate.
5. `05.form_fill_httpbin.gql`
   - Fill a real form and verify interaction outputs.
6. `06.select_dropdown.gql`
   - Inject/select a deterministic dropdown and validate selected value.
7. `07.evaluate_dom.gql`
   - Return structured page analysis via `BROWSER_EVALUATE`.
8. `08.upload_file.gql`
   - Upload a stable local file and verify upload success message.
9. `09.screenshot_capture.gql`
   - Capture page screenshot artifact.
10. `10.implicit_session_chain.gql`
   - Demonstrate implicit session chaining.
11. `11.close_all.gql`
   - Cleanup script to close all sessions.
12. `12.end_to_end_browser_journey.gql`
   - Combined workflow with extraction, interaction, screenshot, and closure.

## Operation Coverage

This course covers:

- `BROWSER_OPEN`, `BROWSER_LIST`, `BROWSER_CLOSE`, `BROWSER_CLOSE_ALL`
- `BROWSER_GOTO`, `BROWSER_WAIT_FOR_SELECTOR`, `BROWSER_WAIT`
- `BROWSER_CLICK`, `BROWSER_TYPE`, `BROWSER_SELECT`, `BROWSER_UPLOAD_FILE`
- `BROWSER_KEYBOARD`, `BROWSER_MOUSE`
- `BROWSER_GET_TEXT`, `BROWSER_GET_HTML`, `BROWSER_GET_ATTR`, `BROWSER_EVALUATE`
- `BROWSER_SCREENSHOT`
