# Data File Fetch

This short course demonstrates how to read complete CSV and JSONL files from mAIcro file storage as GraphQL query results.

## What You'll Learn

- Fetch `orders.jsonl` as an array of JSON records.
- Fetch `products.csv` as an array of objects keyed by CSV headers.
- Use the same `FileDataset` query for both file formats.

The resolver reads and parses the complete file. A successful query returns the complete dataset. Any missing file, unsupported format, malformed row, or other parsing problem returns a GraphQL error instead of partial data.

## Prerequisites

The sample files must already exist in file storage at:

- `maicroverse/customer_orders/orders.jsonl`
- `maicroverse/customer_orders/products.csv`

The files are included in the mAIcroverse `customer_orders` sample data. Import them from Git if they are not present in your instance.

## Script Map

| Script | Purpose |
|--------|---------|
| `01.run_data_file_fetch.gql` | Runs both dataset queries in order |
| `02.fetch_orders.gql` | Fetches the complete `orders.jsonl` dataset |
| `03.fetch_products.gql` | Fetches the complete `products.csv` dataset |

## How To Run

1. Confirm the two files exist in File Storage.
2. Run `01.run_data_file_fetch.gql`.
3. Inspect `orders` and `products` in the returned GraphQL result.

You can also run either numbered fetch script independently.

## Direct Query Examples

```graphql
query FetchOrders {
  FileDataset(path: "maicroverse/customer_orders/orders.jsonl")
}
```

```graphql
query FetchProducts {
  FileDataset(path: "maicroverse/customer_orders/products.csv")
}
```

JSONL preserves JSON values, including nested objects. CSV values are returned as strings keyed by the header row.
