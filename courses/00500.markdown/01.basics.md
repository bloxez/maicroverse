# 1. Text Basics

Everything in Markdown starts with plain text. This lesson covers the rules that decide
where a sentence breaks, how a word is emphasised, and how to write a character that
Markdown would otherwise treat as a command.

## Paragraphs

A paragraph is one or more lines separated from the next block by a blank line.

This is a second paragraph. The blank line above is doing all the work - without it,
these two sentences would join into one block.

## Line Breaks

There are three ways to break a line inside a paragraph.

End a line with two spaces:  
this line starts on a new row.

End a line with a backslash:\
this line does too.

Or use an HTML break:<br>
which is the most explicit of the three.

> In the mAIcro preview, single newlines are already rendered as breaks, so short
> notes behave the way most people expect. Use the explicit forms when you want the
> same file to render identically everywhere else.

## Emphasis

| Intent | Source | Result |
| --- | --- | --- |
| Strong | `**important**` | **important** |
| Emphasis | `*subtle*` | *subtle* |
| Both | `***critical***` | ***critical*** |
| Removed | `~~withdrawn~~` | ~~withdrawn~~ |
| Highlight | `<mark>flagged</mark>` | <mark>flagged</mark> |

Underscores work too - `_like this_` - but they are ignored inside_a_word, which makes
them safer for prose and worse for identifiers.

## Inline Code

Wrap short fragments in backticks: `DbReload`, `const ready = true`, `--watch`.

To show a backtick itself, wrap the fragment in a longer fence: `` `literal backticks` ``.

Inline code is not just decoration. It tells the reader "type this exactly", which is
why command names, field names, and file paths belong in it.

## Escaping

A backslash turns a Markdown character back into an ordinary one.

- `\*not italic\*` renders as \*not italic\*
- `\# not a heading` renders as \# not a heading
- `\| not a table cell \|` renders as \| not a table cell \|

The escapable characters are ``\ ` * _ { } [ ] ( ) # + - . ! |``

## Entities And Symbols

HTML entities pass straight through: &copy; &reg; &trade; &mdash; &rarr; &hellip;
&nbsp;is a non-breaking space, and &lt; and &gt; let you write literal angle brackets.

Emoji are just characters, so paste them directly: 🌤️ 📊 🛰️

## Subscript And Superscript

Water is H<sub>2</sub>O and the area is 12&nbsp;m<sup>2</sup>.
