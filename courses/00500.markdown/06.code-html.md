# 6. Code And HTML

Technical pages live or die on how they present commands and output. This lesson covers
fenced code, and the small set of HTML that Markdown lets through when you need more.

## Fenced Code

Three backticks open and close a block. The word after the opening fence sets the syntax
highlighting.

```typescript
interface StationReading {
  stationId: string;
  recordedAt: string;
  windSpeedKn: number;
}

const reading: StationReading = {
  stationId: "CB-004",
  recordedAt: "2026-08-19T02:00:00Z",
  windSpeedKn: 14.2
};
```

```graphql
query RecentReadings($stationId: String!) {
  weather_readings(where: { station_id: { eq: $stationId } }, limit: 10) {
    recorded_at
    wind_speed_kn
  }
}
```


## Indented Code

Four spaces of indentation also makes a code block. It is fragile and easy to break by
accident, so prefer fences - but you will see it in older documents.

    this line is a code block
    because it is indented four spaces

## Inline HTML

Markdown passes most HTML straight through. Use it for the handful of things Markdown
cannot express.

### Collapsible Detail

<details>
<summary>Show the full instrument list</summary>

| Instrument | Serial | Installed |
| --- | --- | --- |
| Anemometer | AN-2291 | 2024-03-11 |
| Rain gauge | RG-0184 | 2024-03-11 |
| Thermistor | TH-7756 | 2025-01-08 |

</details>

<details>
<summary>Show the recovery procedure</summary>

1. Power down the logger.
2. Wait sixty seconds.
3. Power up and confirm the heartbeat in the console.

</details>

Collapsible blocks keep a page short without hiding anything from search.

### Small Inline Elements

- Highlight: <mark>this needs review</mark>
- Keyboard: press <kbd>Ctrl</kbd> + <kbd>S</kbd> to save
- Abbreviation: <abbr title="Coordinated Universal Time">UTC</abbr>
- Small print: <small>readings before 2024 are unverified</small>
- Inserted and deleted: <ins>added</ins> and <del>removed</del>

### Alignment

<div align="center">
  <strong>Cloudbank Field Station</strong><br>
  Elevation 1,240 m &middot; Established 2024
</div>

### Comments

An HTML comment is invisible in the preview, which makes it the standard way to leave a
note for the next author.

<!-- TODO: confirm the thermistor serial before the next audit -->

## When Not To Use HTML

Every piece of HTML you add is a piece the renderer has to be trusted with, and a piece
that will not survive being converted to another format. Reach for it only when Markdown
genuinely cannot do the job: sizing an image, collapsing a section, or aligning a block.
