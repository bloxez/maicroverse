# 10000.asx_watcher - ASX Watcher Course

This course teaches a practical progression for market monitoring workflows in mAIcro: fetch raw market data, shape it into markdown reports, then use browser automation to extract live web content.

## Safety Notes

- Scripts `05` and `06` open browser sessions and then clean them up in-script.
- No destructive database reset is performed in this course.
- Re-running is expected and supported; each script is safe to execute repeatedly for learning.

## What You'll Build

- A repeatable pipeline for ASX ticker retrieval from Yahoo Finance.
- Markdown output patterns for one or more tickers.
- Browser automation patterns for page navigation and DOM extraction.
- A single setup orchestrator script that runs the full course in order.

## Script Map

1. `01.asx_watcher_setup.gql`
   - Master orchestrator that executes all numbered lesson scripts in order.
2. `02.multi_stock_raw.gql`
   - Fetches raw JSON for `DRO.AX` and `TLX.AX`.
3. `03.single_stock_md.gql`
   - Converts one ticker payload to markdown.
4. `04.multi_stock_md.gql`
   - Converts both tickers to markdown in one run.
5. `05.browser_intro.gql`
   - Opens browser, navigates, extracts table rows, and closes browser.
6. `06.browser_advanced.gql`
   - Multi-step browser interactions, heading extraction, challenge check, cleanup.
