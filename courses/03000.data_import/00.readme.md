# Data Import Story: From Raw Files to Dashboard Insights

This folder is the operational pipeline that turns raw source files into analytics-ready tables and then into dashboard-ready chart payloads.

## Why This Exists

The goal is not only to load data, but to produce a reliable demo narrative:

1. Ingest customer/order/weather inputs.
2. Normalize and merge records into queryable tables.
3. Feed a unified dashboard payload for the Charts panel.

If you want to show the platform value quickly, this is the path to run.

## Source Data

Customer/order source:
https://github.com/bloxez/maicroverse/tree/main/file_storage/customer_orders

Core files used by default:
- customers.csv
- products.csv
- orders.jsonl
- order_items.jsonl

## Script Map

| Script | Role in story |
|--------|----------------|
| 01.run_data_import.gql | End-to-end orchestrator for standard import path |

| 08.import_analytics_extensions.gql | Adds richer operational/behavior analytics inputs |

| dashboard/00.readme.md | Dashboard-specific chart catalog and run notes |

## Dashboard Integration (Important)

The data import flow is complete only when dashboard output is produced.

After import scripts run, execute:
- `scripts/data_import/dashboard/01.data_import_dashboard.gql`

This returns:
- `dashboard.title`, `dashboard.description`
- `dashboard.layout`
- `dashboard.controls`
- `dashboard.charts`
- backing datasets (`orders_dataset`, `invoices_dataset`, `items_dataset`, `customers_dataset`)

Open the Charts panel to render the full dashboard from that single payload.

## Recommended Demo Run Order

1. Run `05.import_customer_data.gql`.
2. Optionally run `08.import_analytics_extensions.gql` for richer analysis depth.
3. Run `dashboard/01.data_import_dashboard.gql`.
4. In Charts panel, walk through chart story:
   - demand and revenue trend,
   - payment/risk signals,
   - stacked operational composition.

## Troubleshooting

- If charts show empty results: rerun `05.import_customer_data.gql` first.
- If expected advanced charts are sparse: run `08.import_analytics_extensions.gql`.
- If labels look odd, verify source fields in `maicroverse/file_storage/customer_orders` and rerun dashboard script.

## Consistency Notes

- Dashboard payloads use `charts` terminology (not `widgets`).
- This folder is designed to align with the Book Club dashboard style: one unified payload per dashboard script.
