# API Wrappers

This folder contains scripts that register external REST APIs as native GraphQL
resolvers using mAIcro's `ApiWrap` mutation. Once registered, any third-party
endpoint becomes a first-class query or mutation in your project's schema —
no custom backend code required.

## What is ApiWrap?

`ApiWrap` turns an HTTP endpoint into a typed GraphQL resolver. You declare:

- **inputs** — the GraphQL arguments the resolver accepts
- **outputs** — the fields it returns
- **responseMapping** — dot-path expressions that map JSON response keys to
  output fields
- **headers** — static headers including API keys (stored securely, never
  exposed in `ApiWrapList`)
- **bodyTemplate** — a JSON template for POST/PUT bodies with `{variable}`
  placeholders
- **throttle / maxConcurrentCalls** — built-in rate limiting per provider

After running `DbReload`, the new resolver is immediately available in the
schema alongside your database queries and mutations.

## Providers

### JSONPlaceholder (no API key)

A free, public fake REST API — ideal for learning `ApiWrap` without signing up
for any service. The setup script registers four resolvers:

| Resolver | Endpoint | Description |
|----------|----------|-------------|
| `JSONPlaceholderPosts` | `/posts` | List all posts |
| `JSONPlaceholderPost` | `/posts?id=` | Single post by ID |
| `JSONPlaceholderUsers` | `/users` | Users with address and company (response mapping demo) |
| `JSONPlaceholderComments` | `/comments?postId=` | Comments filtered by post |

**Start here** if you are new to API Wrappers.

### Brave Search

Web search with rich results powered by the Brave Search API. Requires a free
API key from [brave.com/search/api](https://brave.com/search/api).

Add `BRAVE_API_KEY` in **Settings → Environment**.

Registered resolvers:

| Resolver | Description |
|----------|-------------|
| `BraveWebSearch` | Returns the top result — query, title, URL, description, and age |
| `BraveWebSearchAll` | Returns all results as a JSON array |

Both resolvers include `throttle: 2000` and `maxConcurrentCalls: 1` to stay
within Brave's free-tier rate limits.

### OpenAI Chat

AI chat completions via the OpenAI API. Requires an API key from
[platform.openai.com](https://platform.openai.com/api-keys).

Add `OPENAI_API_KEY` in **Settings → Environment**.

Registered resolvers:

| Resolver | Description |
|----------|-------------|
| `OpenAIChat` | Full-featured — model, system prompt, temperature, max tokens, token usage |
| `OpenAISimpleChat` | Minimal — send a prompt, get text back |

Headers use `{{OPENAI_API_KEY}}` interpolation so the key is read from Settings
at call time and never stored in the schema.

### Pexels Photos

High-quality stock photo search via the Pexels API. Requires a free API key
from [pexels.com/api](https://www.pexels.com/api).

Add `PEXELS_API_KEY` in **Settings → Environment**.

Registered resolvers:

| Resolver | Description |
|----------|-------------|
| `PexelsPhotoSearch` | Search photos by query with orientation and per-page filters |

## Getting Started

1. **No API key needed** — run `API_WRAP_JSON_SETUP.gql` to register the
   JSONPlaceholder resolvers and see the pattern in action.

2. **Add API keys** in **Settings → Environment** for any providers you want
   to use.

3. **Run the SETUP script** for that provider. Each setup script ends with a
   `DbReload` step that makes the new resolvers available immediately.

4. **Run the TEST script** to call the resolver and see the response.

5. **Inspect registered wrappers** at any time:

```graphql
query {
  ApiWrapList {
    name
    operation
    endpoint
    method
  }
}
```

## Key Concepts

### Response Mapping

Dot-path expressions extract values from nested JSON responses:

```
"city": "address.city"          # nested field
"title": "web.results.0.title"  # array index
"text": "choices.0.message.content"
```

### Environment Variable Interpolation

Use `{{VAR_NAME}}` in headers or body templates to reference values stored in
**Settings → Environment** without hardcoding secrets:

```json
{"Authorization": "Bearer {{OPENAI_API_KEY}}"}
```

### Security

API keys in `headers` are stored encrypted and are intentionally excluded from
`ApiWrapList` query results to prevent accidental exposure.
