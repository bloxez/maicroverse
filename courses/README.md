# Self-Contained Training Courses

This folder contains complete, self-contained training courses designed to teach specific topics and skills.

Each course includes:
- **Structured lessons** with clear learning objectives
- **Hands-on exercises** and practical examples
- **Project-based assignments** to reinforce concepts
- **All materials included** — no external dependencies required

These courses can be followed independently or combined to build a comprehensive learning path for mAIcro development and deployment.

## Course Contents (Brief)

- `01000.ai_tasks`: AI task orchestration and automation basics
- `02000.book_club`: Collaborative workflows and discussion-driven exercises
- `02100.memory`: Memory usage patterns for agents and workflows
- `03000.data_import`: Data ingestion and import pipeline fundamentals
- `04000.clients`: Building and using mAIcro client integrations
- `05000.hr_graph`: Graph modeling and HR-style domain examples
- `06000.api_wrappers`: Designing reusable API wrappers
- `07000.cron`: Scheduled jobs, automation timing, and maintenance flows
- `10000.asx_watcher`: Market/watcher-style monitoring workflow example
- `11000.browser_x4m`: Browser automation and X4m integration patterns
- `12000.ai_signatures`: AI signature definitions and invocation usage
- `20000.forms`: Form workflows, validation, and submission handling
