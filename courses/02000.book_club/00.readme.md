# Book Club

**Warning**
Running the Book Club setup will wipe existing project data (including uploaded files) and recreate the full Book Club dataset.

Use a dedicated learning instance when possible.

## Introduction

Book Club demonstrates mAIcro's GraphQL-first model with relational SQL, graph sync, semantic search, row-level security, async analysis workflows, and dashboard payload shaping.

Core capabilities shown:

- Auto-generated GraphQL CRUD APIs from table definitions
- Semantic search via vector-enabled fields
- Apache AGE graph integration on top of SQL-backed entities
- Row-level security using reusable filters
- File storage + metadata for document workflows
- Async jobs for long-running operations
- Team-scoped demo users and notes for permission testing
- Unified dashboard payload design for chart-first UI clients

## What You Build

The setup creates these tables:

| Table | Purpose |
|------|---------|
| readers | Book club members |
| authors | Author records |
| books | Catalog entries |
| reviews | Reader feedback |
| team_notes | Team-scoped internal notes |

Setup flow:

1. Clear database and graph state
2. Enable platform features (files/search/async jobs)
3. Create schema and reload GraphQL
4. Seed readers, authors, books, reviews
5. Build social graph relationships
6. Create Team A / Team B demo users and seed team_notes
7. Verify everything works
8. (Optional) Build a dashboard payload for analytics visualizations

## Dashboard Script (30)

Run `scripts/book_club/30.book_club_dashboard.gql` after setup to get one response containing:

- `dashboard` JSON block (title, controls, chart layout metadata)
- `readers_lookup` for dropdown controls
- chart-ready datasets (`books_by_genre`, `reviews_timeline`, `reviews_flat`, `reader_membership`)
- validation asserts confirming payload shape

This script is intended for frontend/chart clients that want metadata + data in a single request.

## New Companion Workflow (Data Import Integration)

After Book Club setup, you can run the data import scripts to attach identity files to seeded readers.

Key companion scripts in `scripts/data_import`:

- 09.connect_license.gql
  - Downloads AU identity docs
  - Links AU_DL_GOOD_QUALITY.jpg to `pattyb` via:
    - `metadata.custom_fields.$schema = drivers_license`
    - `metadata.custom_fields.reader_id = <patty id>`
  - Queues `FileAnalyze(specs:["task:drivers_license"])`
  - Waits for completion using `AwaitJobCompletion`
  - Verifies relationship and ai_results projection

- 10.patty_details.gql
  - Ad hoc script for Patty profile + activity + linked license details
  - Returns metadata/custom_fields/ai_results in one run
