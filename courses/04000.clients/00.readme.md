# Clients Demo

This folder provides a focused client data workflow for demos that will later integrate with forms and document handling.

## Introduction

The Clients demo shows how to:

- clear existing demo client and document AI state
- create a dedicated `clients` table using `DbTableAdd`
- auto-generate GraphQL CRUD operations via `DbReload`
- seed realistic client rows for downstream form/document linking
- link a drivers license document to a single client and query the typed relationship in sync
- show the final synced client list with one related drivers license record

## What You Build

The setup creates one table:

| Table | Purpose |
|------|---------|
| clients | Canonical person and address profile used for forms and document workflows |

Fields created:

- first_name
- last_name
- middle_name
- dob
- address_unit
- address_street
- address_suburb
- address_state
- address_postcode

## Scripts

- 01.clients_setup.gql - Orchestrates the full clean reset, setup, document demo, and final synced query
- 02.clear_client_data.gql - Clears seeded clients and resets the linked drivers license document
- 03.create_clients_table.gql - Creates `clients` table and reloads schema
- 04.seed_clients.gql - Seeds demo client records
- 05.verify_clients.gql - Verifies table and seeded records
- 06.configure_drivers_license_relationship.gql - Registers the typed drivers license relationship
- 07.link_document_to_client.gql - Links document 82 to the first client
- 08.verify_client_drivers_license_typed.gql - Verifies typed document traversal
- 09.clients_documents_demo.gql - Runs the typed document demo workflow
- 10.query_client_drivers_license.gql - Shows clients and linked drivers license details in sync

## Run Order

1. Run `scripts/clients/01.clients_setup.gql` for the complete end-to-end demo
2. Or run scripts individually in numeric order

## Notes

- Scripts are designed to be rerunnable.
- Run `02.clear_client_data.gql` before the setup/demo flow when you need a clean state.
- The `clients` table is intentionally simple and form-friendly for future joins to forms/documents.
